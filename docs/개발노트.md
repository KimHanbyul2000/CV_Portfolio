# 개발 노트 (내부)

홈페이지·이미지·영상의 **설계 결정과 그 이유**를 적는다. 화면을 바꾸라는 지시서가 아니라,
다음에 손대는 사람(또는 Claude)이 "왜 이렇게 되어 있나"를 알기 위한 기록이다.

## 테마 (라이트 / 다크)

| | |
|---|---|
| 누가 넣었나 | 초안 작성 시 Claude 가 제안해 넣었고, 본인이 유지하기로 함 (2026-09-30) |
| 동작 | 첫 방문은 OS 설정(`prefers-color-scheme`)을 따른다. 오른쪽 위 `◐` 버튼으로 전환하면 그 선택을 브라우저 `localStorage` 에 기억한다 |
| 저장 실패 시 | 사생활 보호 모드 등에서 저장이 막혀도 페이지는 정상 동작한다(try/catch). 기억만 안 될 뿐 |
| 색 정의 위치 | 페이지 색: `index.html` 의 `:root` CSS 변수. 3D 화면 색: `data/surface.json` (다크 = 각 항목의 `color`, 라이트 = `light` 블록) |

### 3D 화면도 테마를 따른다

- 처음엔 3D 화면을 항상 어둡게 고정했다(이미지·영상과 모양을 맞추려고). 본인 질문("3D 반응 영상에는
  적용이 안 되나?")을 받고 **홈페이지의 3D 화면은 테마를 따르도록** 바꿨다 (2026-09-30).
- 구현: `web/surface.js` 의 `setTheme(mode)` 가 캔버스 배경·선·기둥 색을 바꾸고, 3D 화면 요소에
  `data-theme` 을 달아 CSS 가 라벨 배경·캡션 색을 바꾼다. 테마 버튼과 OS 설정 변경 둘 다에서 호출된다.
- **PNG 이미지와 MP4 영상은 항상 어두운 배경이다.** 파일은 한 번 만들어지면 보는 쪽 테마를 알 수 없고,
  포트폴리오 첨부물로서는 한 가지 모양이 낫다. 라이트 버전 파일이 필요해지면 `render.py` 에 팔레트
  인자를 추가해 따로 뽑는다(아직 없음).
- 라이트 팔레트의 색은 다크 팔레트보다 한 단계 진하다 — 밝은 배경에서 같은 색을 쓰면 가는 선이 묻힌다.

### 사용자 사이트와 테마 공유

`https://kimhanbyul2000.github.io/`(저장소 `KimHanbyul2000.github.io`)에도 같은 방식의 테마 버튼을 달았다
(2026-09-30). 두 사이트는 **같은 도메인**이라 `localStorage` 가 공유된다 — 한쪽에서 고른 테마가 다른 쪽에도
이어진다. 저장 키는 둘 다 `"theme"`, 값은 `"light"`/`"dark"`. **한쪽의 키나 값을 바꾸면 다른 쪽도 바꾼다.**
사용자 사이트는 원래 다크 전용이었고, 라이트 색은 이때 추가했다(`css/style.css`).

## 언어 (KR / EN)

오른쪽 위 `EN`/`KO` 버튼으로 페이지 전체를 한국어·영어로 바꾼다 (본인 요청 2026-09-30 — 처음엔 한국어 아래
회색 영어를 병기했는데, 테마 버튼처럼 전환하는 전체 번역으로 바꿨다).

| 문구 종류 | 어디에 두나 | 어떻게 바뀌나 |
|---|---|---|
| 데이터 문구 (이름·직무·카드·본문·타임라인) | `data/profile.json` 의 `*_ko`/`*_en` 또는 `{ko, en}` 쌍 | `index.html` 의 `render()` 가 현재 언어 쪽을 골라 다시 그린다 |
| 고정 문구 (절 제목·표·설명·버튼) | `index.html` 안에 `<span lang="ko">…</span><span lang="en">…</span>` 쌍 | CSS 가 `data-lang` 에 따라 한쪽을 숨긴다. `<html lang>` 자체는 숨기지 않게 `body [lang]` 로 한정 |
| 3D 캡션·버튼 문구 | `index.html` 의 `CAP`·`SURF_MODES` | `setU()`·`render()` 가 언어별로 고른다 |
| 3D 라벨 중 "현재 연도·미래 기대값·깊이" | `web/surface.js` 의 `TXT` | `setLang()` |

- 기둥 이름 라벨(L1~L_now)은 **언어와 무관하게 한·영 병기**다 — 이미지·영상의 라벨과 같은 모양을 유지하려고.
- 선택은 `localStorage` 의 `"lang"` 에 저장된다. 기본은 한국어.
- 새 문구를 추가할 때 **한쪽 언어만 넣지 않는다.** 데이터면 ko/en 둘 다, 고정 문구면 span 쌍으로.
- 본인 작성 본문(`convergence.body_ko`)의 영어판은 Claude 번역이다. 기관 영문명은 KIST 영문 사이트 기준(2026-09-30 확인):

## 링크 미리보기 (og:image)

두 사이트(`CV_Portfolio`, 사용자 사이트) 모두 `assets/img/og.png`(1200×630)를 미리보기 이미지로 쓴다.
`src/render.py` 의 `og_image()` 가 만든다. 사용자 사이트의 `<meta property="og:image">` 도 이 파일의 절대 주소를
가리키므로, **이 파일의 경로를 바꾸면 사용자 사이트도 고친다.** 카카오톡 등은 미리보기를 캐시하므로 바꾼 뒤
바로 반영되지 않을 수 있다.

## 곡면 표시 버튼 (4상태)

`곡면:` 버튼 하나가 **합 → 개별 → 합 + 개별 → 끔** 을 순환한다 (본인 요청 2026-09-30).
처음에는 "개별 곡면 보기" 체크박스 하나였는데, 합(전체 곡면)도 끄고 켤 수 있어야 한다는 요청으로
버튼 하나에 네 상태를 몰았다. 끔 상태는 기둥만 남겨 1단계처럼 구조만 볼 때 쓴다.

## 이미지에서 개별 곡면을 겹쳐 그리지 않는 이유

네 개별 곡면을 전체 곡면과 한 그림에 겹쳐 그려 봤더니 선이 얽혀 읽을 수 없었다(2026-09-30 시도).
그래서 **단계 그림(stage1~4)은 합만**, 개별 곡면은 **분해도(`decomposition.png`)** 로 따로 보여준다.
홈페이지에서는 버튼으로 겹쳐 볼 수 있다(돌려 볼 수 있어 덜 얽혀 보인다).

## 3D 화면의 자동 회전을 끈 이유

자동 회전을 켜 두면 어떤 각도에서는 라벨이 서로 겹친다. 라벨이 겹치지 않도록 고른 각도
(`render.py` 의 `AZIM` = -75°)로 시작하고, 돌려 보는 건 방문자에게 맡긴다.
